Guessing Game

This is a simple Java game where the program picks a random number between 1 and 100, and the player has to guess it.

How it works

- The program generates a random number
- The user enters a guess
- If the guess is too high, the game says "Too high!"
- If the guess is too low, the game says "Too low!"
- The loop continues until the user guesses correctly

Example output:

Guess a number between 1 and 100: 50
Too low!
Guess again
75
Too low!
Guess again
90
Too high!
Guess again
82
Too high!
Guess again
78
You got it right!

It is a small beginner project.
